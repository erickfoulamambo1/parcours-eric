Bac 1 - Introduction au Web

HTML (HyperText Markup Language)

Mes premiers pas dans le Web

Le HTML (HyperText Markup Language) est le langage de balisage fondamental qui permet de créer la structure de toutes les pages web. C'est le premier langage que j'ai appris dans le domaine du développement web durant ma Licence 1. C'est grâce au HTML que j'ai compris comment les sites internet sont construits et comment organiser le contenu.

L'esquisse HTML5 (Arbre DOM)

L'un des concepts les plus importants en HTML est le DOM (Document Object Model). Il s'agit d'une représentation arborescente de la page où chaque balise est un nœud. Voici l'esquisse visuelle :

<!DOCTYPE html>
<html>
<head>
<title> Ma Page </title>
</head>
<body>
<h1> Titre Principal </h1>
<p> Un paragraphe de contenu... </p>
</body>
</html>

Explication ligne par ligne

Dans l'exemple ci-dessus, chaque ligne joue un rôle précis :

  • <!DOCTYPE html> : Indique au navigateur que le document est écrit en HTML5 (la version moderne).
  • <html> ... </html> : C'est la balise racine. Tout le contenu de la page doit se trouver à l'intérieur.
  • <head> ... </head> : Contient les métadonnées (informations sur la page). Le titre de l'onglet (<title>) se trouve ici.
  • <body> ... </body> : C'est la partie visible de la page (ce que l'utilisateur voit à l'écran).
  • <h1> ... </h1> : Le titre principal de la page.
  • <p> ... </p> : Un paragraphe de texte standard.

Les notions essentielles acquises

Au-delà de la structure de base, j'ai appris à utiliser de nombreuses balises pour enrichir le contenu :

  • Balises de titre et de texte : Utilisation des titres (<h1> à <h6>), des paragraphes (<p>), des mises en gras (<strong>) et en italique (<em>).
  • Listes : Création de listes ordonnées (<ol>) et non ordonnées (<ul>) avec des éléments (<li>).
  • Images et liens : Apprentissage de la balise d'image (<img>) et de la balise d'ancrage (<a>) pour naviguer entre les pages.
  • Formulaires : Introduction aux balises de formulaire (<form>, <input>, <button>) pour interagir avec l'utilisateur.
  • Tableaux : Structuration de données avec les balises <table>, <tr> et <td>.

L'importance du HTML

Le HTML est la brique de base de tout projet web. Même si je maîtrise aujourd'hui le CSS et le JavaScript, comprendre la sémantique du HTML est crucial pour construire des sites accessibles et bien structurés. C'est le socle sur lequel tout le reste repose !
