Introduction au PHP

C'est quoi le PHP ?

Le PHP (Hypertext Preprocessor) est un langage de programmation côté serveur. Contrairement au HTML ou au CSS qui sont exécutés par le navigateur de l'utilisateur, le PHP s'exécute sur le serveur (comme un ordinateur distant) avant d'envoyer le résultat final à l'écran. C'est grâce au PHP que les sites peuvent "se souvenir" de nous, gérer des comptes utilisateurs, ou encore envoyer des emails.

Les bases syntaxiques du PHP

Le PHP s'intègre directement dans le HTML. Lorsque le serveur voit <?php ... ?>, il exécute ce qui se trouve à l'intérieur avant d'envoyer la page.

Exemple basique :

<?php
    $nom = "Eric";
    echo "Bonjour " . $nom . " !";
?>

Les notions fondamentales acquises

  • Variables et types de données : Les variables en PHP commencent par un $ et sont dynamiques (on n'a pas besoin de déclarer leur type à l'avance).
  • Structures conditionnelles : Utilisation classique du if, else, elseif pour prendre des décisions.
  • Boucles : Les boucles for et while pour parcourir des listes de données.
  • Fonctions prédéfinies : Découverte de fonctions utiles comme var_dump() pour déboguer, date() pour l'heure.
  • Interaction avec HTML : Comment envoyer des données d'un formulaire HTML vers un script PHP via les méthodes GET et POST.

Connexion avec le SQL

Le point culminant de ce cours a été de comprendre comment lier le PHP à nos Bases de Données SQL. Grâce aux extensions comme mysqli ou PDO, nous avons appris à écrire du code PHP qui interroge la base de données et affiche les résultats sur une page web.

Connexion simple à une base de données :

$conn = new mysqli("localhost", "root", "", "mon_site");
$result = $conn->query("SELECT * FROM etudiants");
while($row = $result->fetch_assoc()) {
    echo $row['nom'];
}

Pourquoi le PHP est un pilier du Web

Sans PHP, la plupart des sites web seraient statiques (impossibles à mettre à jour sans un développeur). Le PHP permet aux sites d'être dynamiques, interactifs et connectés à des données. Couplé au SQL, c'est la base des systèmes de gestion de contenu (comme WordPress) et des plateformes modernes. Apprendre le PHP, c'est comprendre comment le web fonctionne vraiment !
