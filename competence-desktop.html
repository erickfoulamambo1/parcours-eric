Programmation Desktop & Interfaces Graphiques

C'est quoi une application Desktop ?

Une application Desktop (ou application de bureau) est un logiciel qui s'installe directement sur le disque dur d'un ordinateur (PC ou Mac) et s'exécute localement, sans avoir besoin d'Internet pour fonctionner. Exemples concrets : Microsoft Word, Adobe Photoshop, ou Visual Studio Code.

La différence avec le Web et le Mobile

Pour bien comprendre, voici un petit dessin comparatif :

Applications Web

Nécessitent un navigateur et une connexion Internet.

Applications Mobile

Tournent sur smartphones (Android/iOS). Tactile et portables.

Applications Desktop

Installées sur le PC. Puissantes, rapides, pas besoin d'Internet.

Dessinons une interface graphique (GUI)

Contrairement à la programmation en console (où l'on tape du texte noir sur fond blanc), la programmation Desktop utilise des Interfaces Graphiques (GUI). On utilise des bibliothèques comme Swing (Java), WPF (C#) ou Qt (C++). Voici à quoi ressemble une fenêtre d'application Desktop (que nous avons appris à construire) :

Les concepts fondamentaux appris

  • Fenêtres (JFrame) : Le conteneur principal de l'application. C'est la "toile" sur laquelle on va dessiner.
  • Composants (Widgets) : Les boutons (JButton), les champs de texte (JTextField), les étiquettes (JLabel).
  • Gestionnaires de disposition (Layouts) : Comment organiser les composants dans la fenêtre (ex: BorderLayout, GridLayout, FlowLayout).
  • Événements (ActionListener) : Lier les clics de souris à des actions (ex: cliquer sur "Ajouter" déclenche une fonction).
  • Modèle MVC (Modèle-Vue-Contrôleur) : Une architecture qui sépare les données (Modèle) de l'interface (Vue) et de la logique (Contrôleur). C'est très utilisé en Java Swing.

Exemple de code Java Swing (Le bouton qui dit Bonjour) :

JButton btn = new JButton("Cliquez-moi !");
btn.addActionListener(e -> {
    JOptionPane.showMessageDialog(null, "Bonjour !");
});

Pourquoi la Prog. Desktop est toujours d'actualité

Beaucoup de personnes pensent que les applications Web ont tué les applications Desktop. Mais c'est faux ! Les applications Desktop restent indispensables pour les logiciels qui nécessitent une puissance de calcul locale (montage vidéo, jeux vidéo, développement logiciel, CAO). Apprendre à créer des interfaces graphiques m'a permis de comprendre comment les logiciels "dialoguent" avec l'utilisateur.
