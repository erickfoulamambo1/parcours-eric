Projet 1 : La Calculatrice (Code & Explication)

Notre premier projet a été la création d'une calculatrice simple. Voici le code que nous avons écrit :

import flet as ft

def main(page: ft.Page):
    page.title = "Calculatrice Flet"
    page.vertical_alignment = ft.MainAxisAlignment.CENTER

    result = ft.Text(value="0", size=30, text_align=ft.TextAlign.RIGHT)

    def button_click(e):
        result.value += e.control.text
        page.update()

    btn1 = ft.ElevatedButton(text="1", on_click=button_click)
    page.add(ft.Row([result], alignment=ft.MainAxisAlignment.CENTER))
    page.add(ft.Row([btn1], alignment=ft.MainAxisAlignment.CENTER))

ft.app(target=main)

Ligne 1 : import flet as ft

Importe la bibliothèque Flet et la renomme "ft" pour raccourcir les lignes de code suivantes.

Ligne 3 : def main(page):

Définit la fonction principale qui sera exécutée au lancement de l'application. page est la fenêtre de l'application.

Ligne 6 : result = ft.Text(...)

Crée un widget texte qui affichera le résultat de la calculatrice. size=30 définit la taille de la police.

Ligne 8 : def button_click(e):

Définit une fonction qui sera appelée lorsqu'un utilisateur cliquera sur un bouton. e contient les informations de l'événement.

Ligne 13 : ft.ElevatedButton(...)

Crée un bouton surélevé avec le texte "1". Lorsqu'on clique dessus, la fonction button_click est exécutée.

Ligne 15 : ft.app(target=main)

Lance l'application Flet en exécutant la fonction main.

Projet 2 : Clone de l'interface WhatsApp

Pour nous perfectionner, nous avons reproduit l'interface de WhatsApp en utilisant des ListViews et des Images.

import flet as ft

def main(page: ft.Page):
    page.title = "WhatsApp Clone"
    page.theme_mode = ft.ThemeMode.DARK

    chat_list = ft.ListView(
        controls=[
            ft.ListTile(
                leading=ft.CircleAvatar(content=ft.Icon(ft.icons.PERSON)),
                title=ft.Text("Papa"),
                subtitle=ft.Text("Salut, ça va ?")
            )
        ]
    )
    page.add(chat_list)

ft.app(target=main)

Ligne 4 : page.theme_mode = ...

Active le mode sombre (Dark Mode) pour l'application, comme le vrai WhatsApp.

Ligne 6 : ft.ListView(...)

Un conteneur qui permet de faire défiler une liste d'éléments verticalement (comme une liste de contacts).

Ligne 8 : ft.ListTile(...)

Un élément de liste standard. Il contient une image de profil (leading), un titre et un sous-titre.

Ligne 10 : ft.CircleAvatar(...)

Crée un avatar rond (photo de profil) avec une icône de personne par défaut.
