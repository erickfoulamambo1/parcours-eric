Bases de Données & SQL

Pourquoi les Bases de Données ?

Avant d'apprendre le SQL, nous manipulions des variables et des fichiers texte. Mais dans le monde réel, les informations sont trop volumineuses et trop complexes pour être gérées simplement. C'est là qu'intervient le SQL (Structured Query Language). C'est le langage qui permet de parler aux bases de données, de ranger, retrouver et modifier des millions d'informations en une fraction de seconde.

Les commandes fondamentales (DDL & DML)

Nous avons appris à diviser les commandes en deux grandes familles :

  • DDL (Data Definition Language) : Pour créer et modifier la structure de la base (les tables).
  • DML (Data Manipulation Language) : Pour ajouter, lire, modifier ou supprimer les données à l'intérieur.

Exemple de création d'une table (DDL) :

CREATE TABLE Etudiants (
    id INT PRIMARY KEY,
    nom VARCHAR(50),
    age INT
);

Les commandes DML incontournables

Voici les 4 commandes de base que nous avons utilisées tout au long de l'année :

Commande Description Exemple
SELECT Récupérer des données d'une table. SELECT * FROM Etudiants;
INSERT INTO Ajouter une nouvelle ligne dans une table. INSERT INTO Etudiants VALUES (1, 'Eric', 21);
UPDATE Modifier des données existantes. UPDATE Etudiants SET age=22 WHERE id=1;
DELETE Supprimer des lignes d'une table. DELETE FROM Etudiants WHERE id=1;

Le concept des Clés (Primary Key & Foreign Key)

Un des concepts les plus importants est la Clé Primaire (PK). C'est un identifiant unique pour chaque ligne (comme un numéro de carte d'identité). Nous avons aussi appris les Clés Étrangères (FK), qui permettent de lier une table à une autre. C'est ce qui rend les bases de données relationnelles si puissantes.

Lier deux tables (Relation) :

SELECT Etudiants.nom, Notes.valeur
FROM Etudiants
JOIN Notes ON Etudiants.id = Notes.etudiant_id;

Pourquoi le SQL est indispensable

Aujourd'hui, tout (ou presque) est stocké dans une base de données : nos comptes bancaires, les produits des magasins, les profils des réseaux sociaux... Maîtriser le SQL, c'est posséder la clé pour interagir avec le cœur des systèmes informatiques modernes.
