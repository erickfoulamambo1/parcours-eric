Les fondamentaux du Centre Informatique

De la théorie des réseaux à la pratique de l'administration à distance.

1. Les Topologies Réseaux

Les topologies définissent la manière dont les ordinateurs sont connectés entre eux. Nous avons étudié les 4 principales :

  • Topologie en Bus : Tous les ordinateurs sont connectés à un seul câble principal. Simple mais fragile (une coupure arrête tout).
  • Topologie en Anneau : Les ordinateurs sont connectés en cercle. Les données circulent dans un seul sens.
  • Topologie en Étoile : Tous les ordinateurs sont connectés à un commutateur central (Switch). La plus utilisée aujourd'hui.
  • Topologie Maillée : Chaque nœud est connecté à plusieurs autres. Très robuste mais coûteuse (utilisée pour les réseaux dorsaux).

2. Les Protocoles Fondamentaux

Les protocoles sont les règles qui permettent aux machines de communiquer. Nous avons étudié :

  • TCP/IP : Le protocole de base d'Internet. Garantit la livraison des données.
  • UDP : Rapide mais non fiable (utilisé pour les jeux et le streaming).
  • DNS : Traduit les noms de domaine en adresses IP.
  • DHCP : Attribue automatiquement des adresses IP aux machines du réseau.

3. TP Pratique : Microsoft Remote Desktop (RDP)

Le travail pratique de fin de cours portait sur l'administration à distance. Voici le résumé de notre projet :

Définition : Microsoft Remote Desktop est une application qui permet de contrôler un ordinateur à distance via le protocole RDP.

Principe de fonctionnement :
Hôte (L'ordinateur à contrôler) ➡ RDP (Protocole) ➡ Client (L'ordinateur qui contrôle)

Étapes de connexion :
1. Activer le "Bureau à distance" sur l'ordinateur hôte.
2. Connecter les deux machines au même réseau (ou via Internet).
3. Saisir l'adresse IP ou le nom de l'ordinateur hôte et le mot de passe.
4. Contrôler l'ordinateur à distance comme si on y était.

Avantages : Accès à distance, gain de temps, maintenance simplifiée, sécurité (authentification RDP).
Inconvénients : Dépendant de la connexion Internet, risques de sécurité si mal configuré, consommation de ressources.

La Sécurité des Centres Informatiques

La sécurité est un aspect crucial de la gestion d'un centre. Nous avons appris à mettre en place des : mots de passe forts, à activer les pare-feux, à limiter les utilisateurs autorisés, et à maintenir les systèmes à jour.

Acquis du cours :
  • Comprendre l'importance et la construction d'un Centre Informatique.
  • Maîtriser les topologies et protocoles réseaux.
  • Savoir utiliser Microsoft Remote Desktop pour l'administration.
  • Connaître les bases de la sécurité physique et logique.
  • Être capable de gérer les risques et les accès de secours.
