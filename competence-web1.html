LE WEB DYNAMIQUE

Du statique au dynamique

En L1 et L2, nous avons appris le HTML et le CSS pour créer des pages statiques (qui ne changent pas). En Langage de Programmation Web 1, nous avons appris le langage côté serveur (généralement PHP) pour créer des pages dynamiques, qui changent en fonction des actions de l'utilisateur.

Côté Serveur (Back-End)

Le code qui s'exécute sur le serveur avant d'envoyer la page à l'utilisateur. Il gère la logique, les bases de données et la sécurité.

Interaction avec la Base de Données

Connexion à une base de données (MySQL) via le langage serveur pour récupérer, enregistrer et modifier des informations.

Gestion des Utilisateurs

Création de systèmes de connexion, d'inscription et de gestion de sessions pour personnaliser l'expérience de chaque visiteur.

Les bases du Développement Web

Des concepts fondamentaux aux premiers scripts dynamiques.

1. Architecture Client-Serveur

La base du web : le Client (navigateur) envoie une requête au Serveur, qui traite la demande et renvoie une réponse.

Schéma de communication :
Client (Navigateur) ➡ Requête HTTP ➡ Serveur (PHP)
Serveur (PHP) ➡ Requête SQL ➡ Base de données
Base de données ➡ Résultat ➡ Serveur ➡ Réponse HTTP ➡ Client

2. Variables et Structures de Contrôle

Les bases de la programmation appliquées au web : déclarer des variables, utiliser des conditions (if, else) et des boucles (for, while).

Exemple (Code PHP) :
<?php
    $nom = "Eric";
    echo "Bonjour " . $nom . " !";
?>

3. Formulaires et Sessions

L'interactivité utilisateur : récupérer les données d'un formulaire ($_POST), et créer une session pour garder l'utilisateur connecté ($_SESSION).

Exemple (Connexion utilisateur) :
if ($_POST['email'] == "admin@example.com") {
    $_SESSION['user'] = "admin";
    header("Location: dashboard.php");
}

Pourquoi la Programmation Web est essentielle

Le web moderne est dynamique. Des réseaux sociaux aux plateformes d'e-commerce, tout repose sur une logique côté serveur. Ce cours m'a appris à créer des sites qui pensent et réagissent aux utilisateurs.
