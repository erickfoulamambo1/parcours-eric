Les fondamentaux de l'Embarqué

De la platine d'essai au code Arduino, voici les clés des systèmes embarqués.

1. La Platine d'Essai (Breadboard)

La platine d'essai est le premier outil du prototypage électronique. Elle permet de créer des circuits sans soudure.

Composition :
  • Lignes d'alimentation : Les rails rouges (+) et bleus (-) pour fournir du courant.
  • Zone de composants : Les trous au centre pour insérer les puces et les fils.
  • Ponts : Des fils de connexion pour relier les différents composants.

2. Schéma d'un Système Embarqué (Arduino)

Un système embarqué suit toujours le même principe : Entrée ➡ Traitement ➡ Sortie.

CAPTEUR (Entrée) ➡ ARDUINO (Traitement) ➡ ACTIONNEUR (Sortie)

Exemple : Un bouton (Entrée) fait clignoter une LED (Sortie) via le code Arduino.

3. Exemple de Code Arduino (Clignotement LED)

Le langage Arduino est basé sur le C++ et est très simple à prendre en main. Voici le code classique pour faire clignoter une LED (le "Hello World" de l'électronique).

// La fonction setup() s'exécute une fois au démarrage
void setup() {
    pinMode(13, OUTPUT); // Configure la pin 13 comme sortie
}

// La fonction loop() s'exécute en boucle indéfiniment
void loop() {
    digitalWrite(13, HIGH); // Allume la LED
    delay(1000); // Attend 1 seconde (1000 ms)
    digitalWrite(13, LOW); // Éteint la LED
    delay(1000); // Attend 1 seconde
}
