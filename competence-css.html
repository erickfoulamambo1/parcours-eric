Bac 1 - Stylisation

CSS (Cascading Style Sheets)

L'art de la mise en forme

Le CSS (Cascading Style Sheets) est le langage qui permet de contrôler l'apparence visuelle des pages web. Si le HTML est la structure d'une maison, le CSS en est la peinture, la décoration et l'agencement des meubles. Durant ma Licence 1, j'ai appris à transformer de simples pages HTML en interfaces attrayantes et professionnelles.

Les notions fondamentales acquises

Le CSS repose sur trois piliers essentiels que j'ai dû maîtriser :

  • Sélecteurs : Apprendre à cibler les éléments HTML (via leurs balises p, leurs classes .ma-classe, ou leurs identifiants #mon-id).
  • Propriétés et Valeurs : Utilisation des propriétés comme color, font-size, background-color pour modifier le style.
  • Cascade et Héritage : Comprendre comment les styles s'empilent et s'héritent (d'où le nom "Cascading").

Le "Box Model" (Modèle de Boîte)

L'un des concepts les plus importants est le Box Model. En CSS, chaque élément est considéré comme une boîte rectangulaire composée de :

Margin (Espace extérieur)
Border (La bordure)
Padding (Espace intérieur)
Content (Le texte ou l'image)

Comprendre cette boîte est essentiel pour maîtriser les espacements et l'alignement des éléments.

Les Mises en Page (Layouts)

Au-delà du style de base, j'ai appris à structurer des pages complexes en utilisant :

  • Flexbox : Pour aligner des éléments en rangées ou en colonnes, et gérer leurs espacements.
  • CSS Grid : Pour créer des mises en page en grilles (comme des tableaux mais plus puissants).
  • Positionnement : Comprendre les propriétés position: relative, absolute, fixed.
  • Responsive Design : Utilisation des @media queries pour adapter le site aux écrans mobiles.

Pourquoi le CSS est magique

Le CSS est ce qui transforme un site web "d'école" en un site "professionnel". La capacité de séparer le contenu (HTML) du style (CSS) est une pratique fondamentale du développement web. Grâce au CSS, j'ai pu créer les designs épurés, les animations et les dégradés que tu vois sur ce portfolio !
