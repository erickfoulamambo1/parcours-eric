QU'EST-CE QUE MERISE ?

La méthode MERISE en résumé

MERISE (Méthode d'Étude et de Réalisation Informatique pour les Systèmes d'Entreprise) est une méthode de conception de systèmes d'information. Elle permet de modéliser un système d'information en séparant les données et les traitements, et en distinguant les niveaux conceptuel, logique et physique.

Niveau Conceptuel

Le niveau le plus abstrait. Il modélise les règles de gestion et les besoins de l'entreprise, indépendamment des contraintes techniques.

Niveau Logique

Traduit le modèle conceptuel en fonction du type de système (ex: base de données relationnelle). Il définit la structure des données.

Niveau Physique

Le niveau le plus concret. Il prend en compte les contraintes du matériel, du système d'exploitation et des logiciels.

Les 3 Modèles Essentiels

Du conceptuel au physique, voici comment se construit une base de données.

1. Le Modèle Conceptuel de Données (MCD)

Le MCD est la première étape. Il représente les entités (objets du monde réel) et les associations (relations entre entités). Il est indépendant des contraintes techniques.

Exemple : Gestion d'une bibliothèque.
Entités : LIVRE, AUTEUR, EMPRUNT
Associations : ECRIRE (Livre - Auteur), CONCERNER (Emprunt - Livre)
Cardinalités : Un auteur peut écrire plusieurs livres (0,n). Un livre a un seul auteur (1,1).

Le MCD est généralement représenté par un diagramme entité-association.

2. Le Modèle Logique de Données (MLD)

Le MLD traduit le MCD vers un formalisme adapté au système de gestion de base de données (SGBD) choisi. Pour un SGBD relationnel, le MLD se présente sous la forme de tables.

Exemple (Transformé en tables relationnelles) :
LIVRE (id_livre, titre, isbn, id_auteur)
AUTEUR (id_auteur, nom, prenom)
EMPRUNT (id_emprunt, date_emprunt, date_retour, id_livre)

Le MLD permet de créer les clés primaires et les clés étrangères.

3. Le Modèle Physique de Données (MPD)

Le MPD est la dernière étape. Il prend en compte les contraintes physiques du SGBD : types de données (INT, VARCHAR), index, et contraintes d'intégrité. C'est le code SQL qui crée les tables.

Exemple (Code SQL) :
CREATE TABLE LIVRE (
    id_livre INT PRIMARY KEY,
    titre VARCHAR(255),
    isbn VARCHAR(20),
    id_auteur INT,
    FOREIGN KEY (id_auteur) REFERENCES AUTEUR(id_auteur)
);

Le MPD est exécuté pour créer la base de données physique.

Les différences essentielles

La grande force de MERISE est de séparer les préoccupations : Le MCD se concentre sur le "quoi" (les règles de gestion). Le MLD se concentre sur le "comment" (la structure des tables). Le MPD se concentre sur le "où" (les contraintes physiques et le code SQL).
